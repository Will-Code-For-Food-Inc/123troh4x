# Pokemon Platinum Decomp - Emerald Legacy-Style QoL Enhancement Implementation Plan

## Project Overview
This document outlines the comprehensive plan for implementing quality-of-life enhancements for Pokemon Platinum using the pokediamond/pokeplatinum decomp, inspired by Pokemon Emerald Legacy. The goal is to modernize Platinum while preserving its Gen 4 identity.

**Project Location:** `/home/alex/projects/reveng/ds-reveng/projects/pokeplatinum/`

## Core Philosophy
- Preserve Gen 4's core mechanics and feel
- Enhance what exists, don't reinvent
- Make every Pokemon viable for playthrough
- Enable full National Dex completion (483/493 Pokemon)
- All starter Pokemon obtainable post-game

## Implementation Phases

### Phase 1: Critical QoL Features
1. Remove double save confirmation
2. Fast Pokemon Center healing system
3. Enable running indoors
4. Allow HM move deletion (with softlock prevention)
5. Remove trade evolution requirements
6. IV/EV display (already implemented - verify working)

### Phase 2: National Dex Completion
7. Add all starter Pokemon via gifts/encounters
8. Populate post-game areas with National Dex Pokemon
9. Resolve version exclusives (make all available)

### Phase 3: Additional QoL Features
10. Fast surf speed with B button
11. Reduce low HP beep to 3 times
12. Bag improvements (sorting, expansion, auto-PC)
13. Berry system overhaul
14. Persistent world states
15. Additional UI/UX improvements
